# Linear issue template: Feature

Create this as an issue template in Linear (Settings > Templates). Issues written this way give
`/factory-start` and `/speckit-specify` everything they need, so clarify has little to ask.

---

## Goal
One or two sentences: what the user or system can do when this is done.

## Inputs and data sources
- Where the data comes from (API, event, user input), with links to docs.

## Outputs
- What the user sees or what the system exposes: screens, routes, APIs, events, files.

## Acceptance checks
- [ ] Observable, testable outcome 1
- [ ] Observable, testable outcome 2

## Out of scope
- What this issue deliberately does not cover.

## Notes
- Edge cases, constraints, examples.
